# Phase 1 scope

## Goal
Turn the existing Jekyll repository from a clone of the old counselling site into the foundation of the new Mente Mirror ecosystem website while keeping GitHub Pages and allowing legacy pages to coexist during migration.

## Website / app boundary

### Website (`mentemirror.com`)
Brand, education, trust, audiences, wellness concepts, AI/Mjuzi explanation, psychologists, services, pricing/resources and calls to action.

### App (`app.mentemirror.com` / mobile app)
User accounts, dashboards, AI companion sessions, assessments, wearable data, scores, interventions, family dashboards, therapy-session experience and personal timelines.

## Phase 1 acceptance criteria

- New homepage no longer presents Mente Mirror only as online counselling.
- Main navigation reflects the new seven-part architecture.
- Homepage explains the five-step journey.
- Homepage introduces the Five Wells framework.
- Homepage explains AI + Psychology + Human Care.
- Homepage introduces Mjuzi without pretending the app functionality runs on the static site.
- CTAs clearly route users toward assessment, AI wellness or human care.
- Layout works on desktop, tablet and mobile.
- Existing Jekyll/Minimal Mistakes pages can remain during migration.
